# images

The logo, `architecture-portfolio.svg`, and one folder per project. The folder name is the project's slug in `data/projects.js`: `in-the-quarry`, `shifted`, `womens-house`, `lean-to`, `sagvaag-senior-garden`, `passage`.

A project folder holds that project's image files and nothing else. The filenames are the ones named in `data/projects.js`. Adding a project means a new folder plus its entry in that file.

The principle's word for this folder is not settled (`workflow/docs/03-architecture.md` § 1). It is held by the project and holds the logo and the six project folders.
